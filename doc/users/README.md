# User and operator guides

These guides help you install, configure, run, and operate the Mail Agent, Wiki
Agent, and their MCP servers. They point to the detailed guides under `docs/`.

## Guides

- [Get started](getting-started.md): install an isolated environment and run an
  agent with the delivered local dataset
- [Wiki Agent](wiki-agent.md): grounded answers, access restrictions, drafts,
  writes, and confirmation
- [Mail Agent](mail-agent.md): mailbox tasks, mock data, HTTP calls, and
  confirmation
- [MCP servers](mcp-servers.md): local, third-party, and HTTP server choices
- [Configuration and deployment](configuration-and-deployment.md): delivered
  configuration, secrets, containers, and health checks
